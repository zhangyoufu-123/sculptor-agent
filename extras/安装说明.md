# 在 macOS 右键菜单里加"在 Sculptor 中修改"

## 安装

1. 双击 `Sculptor 引用服务.workflow`（Automator 快速操作）；
2. 点击"安装"；
3. 系统设置 → 隐私与安全性 → 辅助功能 里给 **Automator** 授权（弹窗询问时允许）；
4. 重启需要使用该功能的 App（Typora / TextEdit / 备忘录等）。

## 用法

1. 在 md 文档里**选中一句话**；
2. 右键 → 服务 → **在 Sculptor 中修改**；
3. 弹出的对话框输入修改指令（例如"这句太文艺，收一点"）；
4. Sculptor 自动在项目里定位到那句话、只改那一处、并把改动吸收进风格档案。

## 可配置项（环境变量）

- `SCULPTOR_BIN`：sculptor 可执行文件路径（默认 `~/.local/bin/sculptor`）
- `SCULPTOR_PROJECT`：文档所在项目目录（默认 `~/Documents`），point-edit 会在该目录内搜索引用；
  建议设置成你自己的写作项目目录，搜索更快也更精准

## 兜底方式（不装服务也能用）

选中文字 → 复制 → 在 Sculptor 对话里粘贴并说明指令：

> 〔Sculptor 引用〕《选中的原句》
> 修改指令：这句太文艺，收一点

CLI 直接调用：

```bash
sculptor point-edit "选中的原句" "修改指令" --dir 项目目录
```

> 说明：Automator 服务包为最佳努力产物（沙箱内无法用 GUI 验证）；如果双击打不开，直接用上面的兜底方式，效果完全一致。
