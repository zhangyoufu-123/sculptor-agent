## 二、热门插件的用户画像:DSH 用户是谁

1. **程序员为主,但要的是"输出"**:最火的不是写代码工具,而是
   **把代码/项目变成漂亮产物**的——架构图(archify)、设计稿(open-design/openpencil)、
   评审报告(brooks-lint)。程序员不是不会写代码,是**不想/不擅长把成果讲成人话**。
2. **视觉优先**:Top 插件一半是视觉/设计类;文字输出类稀缺。
3. **本地优先 + 数据主权**:open-design 主打 local-first——与 Stylotrace 的
   BYOK/本地工作区/风格档案随身完全同频。
4. **生态位空白确认**:**没有任何写作 Agent,更没有风格学习 Agent**。
   "文字输出"大类里只有单点工具(格式转换、摘要),没有"读懂你、替你写、越写越像你"的纵深 agent。

## 三、同类扫描:有没有跟"我们思路一样"的

| 方向 | 生态内 | 结论 |
|---|---|---|
| 风格学习/个人文风 | **无** | 空白,我们是第一个 |
| 写作工作流(澄清→大纲→成稿→审计) | **无** | 空白 |
| 项目→文档/图(archify) | 有(架构图) | 相邻;**我们补上"项目→文字报告/文章"这一半** |
| 深度分析输出(brooks-lint) | 有(代码评审) | 相邻;我们补上"文字质量/风格/读者视角"的分析输出 |
| 选中文本→改进(dsh-annotation) | 有(批注转发) | 相邻;**我们补上"选中→按我的风格精修"** |
| 产出文件展示(deliverables) | DSH 内置(仅链接) | 我们补上"作品 chip + 可复制路径" |
| **越用越懂你(长期记忆/用户画像)** | **有,且很火** | **互补,不是竞争**(见下) |

### 与"越用越懂你"类插件的互补关系(重点)

用户最近关注的 [dsh-memory-evolve](https://github.com/csyangwen/dsh-memory-evolve)(80⭐,社区热议)
主打"**越用越懂你,换会话不丢上下文**":五轨记忆(用户档案/全局事实/项目关键记忆/项目日志/每日日志)
+ **情绪反馈记录**(把"太好了/怎么还没改对"记入日志,积累后分析) + 技能自我进化。

**它的"懂你"= 记住你说过什么、你满意什么(事实记忆);
Stylotrace 的"懂你"= 学会你会怎么写、你亲手改过什么(生成偏好)。两者互补,可以共存:**

| 维度 | dsh-memory-evolve | Stylotrace |
|---|---|---|
| 记忆对象 | 事实/偏好/项目决策/情绪评价 | 写作风格/亲手修改/思想脉络/知识库 |
| 持久化 | `~/.dsh/settings.yaml` 命名空间 | `.stylotrace/` 工作区 vault(可导出随身) |
| 如何影响 AI | 每回合注入"你说了什么" | 写作时注入"你会怎么写"+ 外层调制器评分选优 |
| 情绪反馈 | 记录 + 分析满意度 | **立即转化为风格学习**(`applyStyleDirection`:"太文艺/收一点"→ 更新档案 → 触发 restyle) |
| 自我进化 | 蒸馏工作流成 skill | 蒸馏个人写作 skill + 风格档案持续更新 |

**建议**:两者可同时安装,分工是"它记事实,我学文风"。发布叙事里明确这一互补关系,
避免被误判为同类竞争。

## 四、取长补短:我们从热门插件学到了什么

| 热门插件 | 它的长处 | 我们学到/落地 |
|---|---|---|
| archify(12.8k⭐) | 项目→漂亮产物,零配置 | **落地 `synthesize`**:项目→实验报告/产品介绍/综述/README,零配置、自动提炼 |
| brooks-lint(1.3k⭐) | 基于已有内容做有出处的深度输出 | 已有:事实分级核查 + GB/T 7714 参考文献 + 论证链检查 |
| dsh-annotation | 选中→批注→发送的极简交互 | **落地 Web client 插件**:选中→「Stylotrace 引用」→按风格精修 |
| DSH deliverables | 产出文件可点击 | **落地作品 chip 识别**,让自动提炼的报告一眼可见 |
| open-design | local-first 数据主权 | 已有:BYOK、本地工作区、风格档案可导出随身 |

## 五、差异化定位(发布叙事用)

> **DSH 生态第一个"写作合伙人"**:不是又一个生成器,而是会学习你文风、
> 从项目里替你提炼成文的深度协作写作 Agent。
>
> - 对程序员:做出了东西不想写报告 → `synthesize` 自动提炼成实验报告/产品介绍/综述;
> - 对写作者:先读懂你,再陪你写好 → 四层风格向量 + 外层调制器 + 读者群像;
> - 对生态:40 个 MCP 工具、跨宿主技能包、Web 端选中改进与作品展示——工具链级集成,不是孤立页面。

## 六、发布后要盯的生态动向

- archify 式的"项目→产物"会不会有人跟进写作版:我们已占位(第一个);
- DSH 官方 curated 仓库(dsh-external)开放时间:开放后第一时间提交收录;
- awesome-dsh-plugin 分类:我们建议新增 "Writing & Style",后续同类会进这个桶。
