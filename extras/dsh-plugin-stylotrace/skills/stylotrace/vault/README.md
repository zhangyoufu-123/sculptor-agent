# 风格金库（Style Vault）

这是 Stylotrace 最核心的持久化资产，双风格分离存储：

- `write-style.json` — 人想写的：语言习惯、联想链、句式、不完美痕迹。
- `read-style.json` — 人想听的：结构、节奏、信息密度、情感曲线。
- `style-fingerprint.json` — 压缩守卫用的风格指纹摘要，压缩前更新。
- `project-memory/` — 项目级素材、大纲、红队记录。

原则：

1. 每次产出与每次用户修改后增量更新，不整档重写。
2. 修改频率高的维度 = 用户敏感维度，写作时重点遵守。
3. 本地存储、可导出可删除。隐私优先。
