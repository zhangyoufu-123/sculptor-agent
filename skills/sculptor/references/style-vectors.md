# 风格向量方法论（核心资产）

## 第一性原理

**风格 = 人的不规范表达与完美表达之间的差异。** AI 的默认输出是"完美表达"——平滑、对称、无风险。人的风格是偏离：注意力残差（注意力在句子里停顿、拐弯的地方）、有限知识库里的无限联想（个人经验导致的比喻与跳跃）、不规则的节奏、隐藏的立场。**风格向量测量的不是"人写了什么"，而是"人偏离 AI 默认值的方式"。**

这意味着：

- 采样时，不仅看用户用了什么词，更看他在哪里**没**用常规表达。
- 用户改稿时，改得越用力，说明 AI 的预测偏差越大，越是风格信号。
- 无法解释的跳跃与笨拙，往往是风格最真实的地方，不要"修好"它。

## 双风格模型（人想写的 ≠ 人想听的）

- **write-style（写作风格档案）**：用户写的时候的语言习惯——语气、联想链、句式、不完美痕迹。回答"这句话如果是这个人写的，会怎么说"。
- **read-style（接收风格档案）**：用户/读者愿意怎么被组织——结构、节奏、信息密度、情感曲线。回答"读者读到什么节奏会觉得顺、觉得被尊重"。

产出规则：**语言层服从 write-style，结构层服从 read-style。** 两者冲突时先问用户。

## 3D 风格向量

1. **Personal Dataset（512 维）**：个人联想、惯用技巧、词汇模式。来源：样本 + 每次选择 + 每次修改。
2. **Writing Deviation（128 维）**：用户相对 AI 默认偏好的偏离向量——风格的"差异面"。
3. **Attention Focus（动态稀疏）**：用户反复聚焦的对象/场景/意象（如"旧朝宫人""桂花树""蒲扇"）。

学习规则（在线学习）：预测 → 用户实际选择 → 偏差 = 实际 − 预测 → 向量沿偏差方向更新。用户修改频率高的维度 = 敏感维度，写作时必须重点遵守。

## 14 个规范维度

| 维度                          | 问的是                 | 示例信号                       |
| ----------------------------- | ---------------------- | ------------------------------ |
| temperature 语气温度          | 冷还是暖，主观还是克制 | 常用"我总觉得" vs 不用第一人称 |
| sentencePreference 句式偏好   | 短句、长句还是混合     | 平均句长、最常用句式           |
| modifierDensity 修饰密度      | 细节与修饰的浓淡       | 形容词/副词频率                |
| languageRegister 语域         | 口语化还是书面化       | 会不会用方言、网络词           |
| emotionalSpectrum 情感频谱    | 主要情绪域             | 怀旧、愤怒、平静、昂扬         |
| narrativePerspective 叙述视角 | 第一人称/旁观/全知     | 视角是否稳定                   |
| imageryTendency 意象倾向      | 画面感与意象密度       | 比喻来源（自然/器物/历史）     |
| rhythm 节奏                   | 快慢与呼吸感           | 逗号密度、段落长度             |
| rhetoricalDevices 修辞手法    | 惯用修辞               | 白描 vs 排比 vs 通感           |
| dialogueRatio 对话比例        | 引语与对话多少         | 直接引语频率                   |
| timeHandling 时间处理         | 顺叙/倒叙/闪回         | 时间词分布                     |
| endingPattern 结尾模式        | 收束方式               | 留白 vs 点题 vs 升华           |
| criticalStance 批判姿态       | 是否带立场与批判       | 反问句、价值判断密度           |
| vocabularyCharacter 词汇特色  | 词汇指纹               | 高频专属词、生僻词             |

每个维度记录：值 + 置信度（0-1）+ 证据片段（来自哪句话/哪次修改）。

## 4 遍采样管线

- **Pass 1 计算特征**（快，不用 LLM）：句长分布、标点频率、段落节奏、词频、常用双字词。
- **Pass 2 LLM 深析**：把样本映射到 14 维，每维给出值、置信度、证据原文。
- **Pass 3 比较锚定**：把用户放进风格空间——靠近谁？（鲁迅式/散文式/新闻式/口语式）
- **Pass 4 向量播种**：把画像转成 3D 向量，供后续预测与增量学习。

## 采样规则

1. **同文体优先**：演讲稿要演讲稿样本，论文要论文样本。不同文体的风格侧面不同。
2. **样本量**：<300 字只做 Pass 1 + 轻量 Pass 2，置信度上限 0.3，不展示诊断面板；300-1000 字做 Pass 1-3；>1000 字做全 4 遍。
3. **只展示已确认特征**：confidence > 0.6 才展示，用自然语言描述，不用技术标签。
4. **无样本不硬采**：没有同文体样本就说明"我会在写作中慢慢学"，写作中通过修改吸收。

## 从修改中学习（最重要的信号源）

用户手动改或让 AI 改某处，不是纠错，是风格教学。每次修改记录：

- 改了哪里（句子/比喻/结构/用词）
- 改成了什么（用户的目标表达原文）
- 为什么改（用户说出的意图，或从上下文推断）

然后把"用户偏好方向"写入 write-style 对应维度并提高置信度。修改记录本身也是 read-style 信号：用户受不了的结构问题记入 read-style。

用工具落地：

```bash
node scripts/sculptor.mjs absorb .sculptor/vault edit.json   # 吸收修改（格式见 point-edit.md）
node scripts/sculptor.mjs fingerprint .sculptor/vault        # 刷新风格指纹
```

## 压缩守卫

上下文压缩前，把以下内容写回 `vault/style-fingerprint.json`：

- 14 维中置信度 > 0.6 的值 + 证据短语
- 3D 向量 top 联想 / top 技巧 / top 注意力目标
- 本会话风格增量（新增样本摘要 + 修改吸收记录）

压缩后凭指纹续写。**宁可丢事实细节，不可丢风格指纹**（persona collapse 原理：摘要会剥掉"怎么说"，只留"说了什么"）。

## 风格注入要点

- 注入不是贴标签，是**约束生成分布**：写每句时先问"这句他会怎么写？"
- 对比检查：写完后挑 3 句，问"换成 AI 默认会怎么写"——差异处就是风格兑现处。
- 风格不足时：宁可用更"笨拙但真实"的表达，不用更"流畅但 AI"的表达。
