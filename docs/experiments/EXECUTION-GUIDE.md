# 实验执行手册（指导老师 / 参赛者用）

配套研究论文《SCULPTOR：以"作者建模"为中心的深度协作写作 Agent》第 5.3 节。
本文档说明三个实验怎么执行、数据怎么采集、怎么变成论文里的表格。

## 0. 伦理声明（先读）

1. **知情同意**：每位参与者（作者样本提供者、盲评人）都需知道数据用途——仅用于本研究，匿名保存，不用于其他用途。可口头说明，建议保留记录。
2. **隐私**：作者样本（旧稿）可能含个人信息，文件名与论文中一律用"作者A/B/C"代替真名；样本文件权限 0600，不外传。
3. **诚实**：实验数据和结果必须真实。LLM 生成文本要如实说明；不要为了"结果好看"挑选样本或篡改指标。
4. **辅助工具声明**：论文需声明"本文使用 AI 辅助完成实验设计、文本生成与数据分析"，并说明使用方式。

## 1. 样本收集规范

- 每位作者提供 **1–2 篇同文体旧稿**（议论文/散文/演讲稿任选一种），每篇 **≥300 字**（建议 500–800 字）。
- 旧稿必须是作者本人写的（手写/打字均可），最好与实验题目同文体——这是"风格可迁移"的前提。
- 每篇存成独立 `.md` 文件，命名如 `data/作者A-散文.md`，文件内只放正文。
- 目标：**10–20 位作者**（实验一），盲评人 **≥3 位**（建议 5 位）。

## 2. 实验一：风格保真度对照

```bash
# 1) 采集每位作者的语料包（可选，用于论文"数据"小节）
sculptor experiment collect --workspace .sculptor-exp

# 2) 批量跑对照：同一题目，每位作者出两篇（baseline=通用LLM / variant=SCULPTOR风格注入）
sculptor experiment run \
  --topic "我的暑假" --genre 散文 --words 800 \
  --authors "作者A=data/作者A.md;作者B=data/作者B.md" \
  --workspace .sculptor-exp

# 3) 导出盲评问卷（一页纸，可直接发微信/问卷星）
sculptor experiment blind vault/experiments/run-<时间戳>/ --out 盲评问卷.md
```

**盲评流程**：把"盲评问卷.md"发给 ≥3 位盲评人；每人独立作答（选 A/B/难以判断 + 一句理由）；
收回后把答案整理成 `answers.json`：

```json
[{"pairIndex":0,"choice":"A"},{"pairIndex":1,"choice":"B"},{"pairIndex":2,"choice":"none"}]
```

（`pairIndex` 从 0 开始对应 blind.json 的顺序；`choice` 是问卷上的 A/B/none。）

**汇总成论文表格**：

```bash
sculptor experiment summarize vault/experiments/run-<时间戳>/ --answers answers.json
```

输出 `summary.md`：客观指标表 + 盲评选择率 + 二项检验（z 值）。论文里需按 blind.json
的 `source` 字段把"选了 A/B"换算成"选了 baseline/variant"，再报告 variant 选中率是否显著 >50%。

## 3. 实验二：消融实验

任选 3–5 位作者，对每人跑：

```bash
sculptor experiment ablation \
  --topic "我的暑假" --genre 散文 --words 800 \
  --author data/作者A.md --workspace .sculptor-exp
```

输出 5 个变体（完整/去风格少样本/去侧写/去知识库/去风格档案）的指标。
论文中报告：去掉哪个模块后"更接近 AI 腔"（黑名单↑、TTR↓、句长σ↓）——该模块的边际贡献。

## 4. 实验三：用户体验

```bash
sculptor experiment survey
```

找 10 位参与者，每人完成一次完整写作任务（用 Sculptor 写一篇 600–800 字文章），
记录：澄清轮数、修改次数、耗时、理解度/掌控感/满意度/AI 味评分（1–5）。
对照组：另 10 人直接用通用 LLM 对话完成同样任务，记录同款指标。
论文中报告两组均值与差异。

## 5. 把数据写进论文

拿到数据后：

1. 把 `summary.md` 的表格贴进论文第 5.4 节"结果"；
2. 补写"讨论"：为什么 variant 更接近真人（或为什么某项指标没有差异）；
3. 更新摘要中的结论句与第 5.2 节的样例指标（注明样本量 N）；
4. 参考文献补上统计方法（如 scipy 文档或统计学教材）。

## 6. 时间建议（供参考）

- 第 1 周：联系 10–20 位同学收集旧稿 + 同意说明；
- 第 2 周：跑实验一/二，发盲评问卷；
- 第 3 周：回收盲评 + 用户体验问卷，汇总统计；
- 第 4 周：写结果与讨论章节，定稿。
