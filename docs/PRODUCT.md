# Sculptor 产品文档

> 深度协作写作 Agent · 不只是生成器，而是"懂你的写作搭子"

版本：v0.13.0 · 形态：可一键安装的 skill 包（内嵌完整 agent 引擎）+ 独立 CLI + MCP 服务器

## 一、这是什么

Sculptor 是一个**承上启下的写作 Agent**：它读你、问你、写给你，而不是替你"憋"一篇。

- 它装在 Codex / Claude Code / OpenCode / Cursor 里，作为写作生态位的专职 Agent；
- 它**主导写作对话**（导演模式），只在真正的决策点停下等你；
- 它的产出是"这个人类作者会写"的文字，不是"AI 腔"的范文；
- 它把**风格当作灵魂**：从你的每一句话、每一次亲手修改中在线学习，压缩也不遗忘。

一句话：**人想写的 ≠ 人想听的**——Sculptor 用 write-style（语言习惯）和 read-style（接收结构）两套档案分别建模，让文章既像你写的，又让读者读得进。

## 二、核心工作流

```
观察 → 澄清（一次一问） → 大纲（评审修订） → 逐节写作（双风格注入）
    → 红队审计 → 静默质量门 → 读者群像 + 交锋 → 交付
        ↑____________ 用户方向/修改建议 = 风格反馈，自动重写 ____________↓
```

1. **澄清（Clarify）**：grilling 式追问设计师——问题从你的原话里生长，一次只问一件，每个问题都给出 AI 的建议选项；连续两次"没更多了/你决定"立即收手。
2. **大纲（Outline）**：素材门槛不足**禁止生成**；生成后自动评审（立意贯穿/论点挂载/逻辑递进/素材利用/篇幅/文体规范），低分自动修订，仍需你确认。
3. **逐节写作（Write）**：每节注入你的双风格档案、风格少样本（旧稿+修改对）、风格适配卡、文体范式；每节写完即时"风格脉搏"评分，建议自动带入下一节。
4. **红队审计（Red Team）**：黑名单套话、重复比喻、重复句式、统计指标（句长标准差/段落变异/句首去重/词汇 TTR）全查；不通过自动按你的风格修订。
5. **静默质量门（Quality Gate）**：风格保真评估（低分自动微调）、原创性检查、校对扫描、事实核查 + 联网 RAG 检索请求——**全部真实执行，只记录不刷屏**。
6. **读者群像 + 交锋（Audience + Debate）**：8 位"第一读者"独立反馈，分歧最大的 3 位进入交锋，收敛出**共识（直接改）/ 争议（作者拍板）/ 优先级**。
7. **交付（Deliver）**：自动归档进个人写作库、蒸馏个人 skill、压缩风格适配卡、导出 docx；交付消息只给结果，不罗列评估过程。

## 三、功能清单

### 风格系统（护城河）
- 14 维写作档案（write-style）+ 7 维接收档案（read-style），全部带置信度与证据；
- **风格脉搏**：澄清每轮/大纲/每节写作后即时采集与评估，几十毫秒、零额外 LLM；
- **风格少样本检索**：按论题 BM25 检索你的旧稿与亲手修改对，注入写作提示；
- **风格适配卡**：全部素材压缩成 ≤600 字卡片，写作时最高优先级注入；
- **修改即反馈**：你说"太文艺了/太啰嗦/结尾收一点"，自动收紧档案维度并按它重写；
- **持续微调**：偏好对数据集（Reverse Instructions）+ 本地 LoRA（Panza 式）或 API 微调；
- **压缩守卫**：上下文压缩前刷新风格指纹，记忆丢、风格不丢。

### 质量保障（自我检测，内置不刷屏）
- 反 AI 审计（黑名单/重复比喻/句式/统计指标）；
- 风格保真评估（LLM + 确定性集成评分）；
- 校对纠错（错别字/易混词/叠字/标点，确定性 + LLM 语病）；
- 事实核查（数字/年代/引文/人名/机构分级 material/common/verify）；
- 原创性检查（文内重复句/与个人库自我复用/模板句）；
- **联网 RAG**：verify 项自动生成检索查询——直连端点或宿主代检，结果回灌缓存与素材；
- 读者群像 + 交锋辩论（MAJ-EVAL 式）。

### 写作能力
- **25 种文体**：公文 15 文种（GB/T 9704 排版导出）+ 合同/通知/纪要/报告/议论文/散文/演讲稿/记叙文/学术论文/新闻稿/邮件/视频脚本；
- **参考文献**：GB/T 7714 与 APA 7 生成（期刊/图书/网页/报纸/论文/报告）；
- **一键改写矩阵**：扩写/缩写/续写/仿写/润色/改语气（formal/casual/warm/authoritative）；
- **定点修改**：选中原句 → 〔Sculptor 引用〕块 → 只改那一处并吸收进风格档案；
- **版本快照 + 回滚**：每次写作/改写/审计前自动快照（最多 30 份），永不丢稿；
- **个人写作库**：作品自动分类归档 + 蒸馏"这类文体你的写法"。

### 多模态输入输出
- 输入：docx / xlsx / md / txt / 图片（视觉模型）/ **音频口述（whisper）**；
- 输出：docx（普通/公文国标/学术排版）、html、pdf（内置中文字体）、srt（视频脚本转字幕）、md；
- 语音口述：`sculptor dictate <音频> [--to-draft]`，转录成素材或口述草稿。

### 工程形态
- **Skill 包**：`skills/sculptor/` 内嵌完整引擎（`scripts/engine/`，CI 防漂移），装 skill 即装 agent；
- **独立 CLI**：`agent/bin/sculptor.js`（或 `./install.sh --cli` 软链）；
- **MCP 服务器**：35 个工具，供 Codex / Claude Code / OpenCode 通过标准 MCP 调用；
- **导演模式**：`sculptor agent` 自主决策主导全程；`agent --once` 单步接入宿主；
- **生态位探测**：`sculptor probe` 判断任务是否值得介入，只提议一次、被拒即退让；
- **共存与退让**：只写自己的工作区，外部修改一律退让不覆盖（并发守卫）。

## 四、设计思路

### 1. 人是主体，AI 是搭子
Sculptor 不抢"作者"身份：先问后写、素材不足不生成、大纲必须确认、你随时可以改。AI 负责把模糊的念头变成结构，把"你想说的"变成"读者能听懂的"。

### 2. 风格不是装饰，是灵魂
风格不是"模仿模板"，而是**你的不规范表达与完美表达之间的差异**——那种不可预测、有困惑感、来自个人有限知识库的联想与注意力残差。Sculptor 不抹平它，而是捕捉它、放大它：
- 你的**旧稿**是最高质量的风格证据；
- 你的**亲手修改**是最深的风格信号（原文→改后→意图）；
- 你的**口头修改建议**是评估反馈；
- 每轮对话、每次压缩，风格档案都持续更新并受保护。

### 3. 人想写的 ≠ 人想听的
两套档案分开建模：write-style 管"像不像你写的"（句长/语气/意象/词汇），read-style 管"读者读起来舒不舒服"（节奏/信息密度/开头抓人/结尾余味）。写作时双注入，避免"很有个性但没人读得下去"和"很顺滑但完全没有你"。

### 4. 评估拆进每一轮，不搞交付前大考
风格评估不是最后集中轰炸，而是**每轮交互的轻量脉搏**：澄清学到什么、大纲结构合不合习惯、每节写完即时打分并带入下一节。交付前的静默质量门做兜底，但用户只看结果。

### 5. 感性与理性的分工
- **理性层**：文体范式、大纲评审、红队指标、事实核查、校对——确定性强，交给规则与确定性检查；
- **感性层**：读者群像、交锋辩论、感性解剖（立场/局限/困惑/多视角/风格兑现度）——模拟"人第一次读的心理活动"，AI 的感性只能靠多视角模拟逼近。

### 6. 与宿主生态共生，不打架
退让是底线：只写 `.sculptor/` 工作区，外部改动不覆盖；MCP 被动，宿主不调用就不执行；缺信息反向请宿主代问；联网检索默认走宿主代检（requests.jsonl），可选直连。

## 五、设计亮点（与行业对比）

| 维度 | 我们 | 行业参考 | 差异 |
|---|---|---|---|
| 风格学习 | 双档案 + 少样本检索 + 适配卡 + LoRA + 每轮脉搏 + 修改反馈闭环 | Grammarly custom voice / Sudowrite Story Bible（静态设定） | 我们是**动态在线学习**，修改即训练 |
| 评估 | 静默质量门真实触发，不刷屏 | 多数产品交付时展示一堆评估 | 用户体感更干净，质量不缩水 |
| 读者反馈 | 8 人群像 + MAJ-EVAL 式交锋（共识/争议/优先级） | 少数产品有单读者反馈 | 把"读者反应"做成可执行决策 |
| 反 AI 痕迹 | 黑名单 + 重复比喻/句式 + 统计指标 + 风格保真集成评分 | 通用"去 AI 味"提示 | 有硬性检查与自动修订闭环 |
| 事实核查 | 分级 + 联网 RAG 查证 | 多数只标注"请核对" | 从"提醒"升级到"去查" |
| 文体/格式 | 25 种文体 + GB/T 9704 公文 + 学术排版 + 参考文献 | 讯飞公文/秘塔学术垂直深耕 | 通用 + 垂直兼顾 |
| 工程形态 | skill 内嵌引擎 + CLI + MCP，装 skill 即装 agent | 多为 SaaS 或插件 | 可嵌入任何 agent 宿主，离线兜底 |
| 数据主权 | 全部本地/工作区，风格档案可导出随身 | 云端为主 | 隐私与可携带性 |

```
│   ├── bin/sculptor.js        # CLI 入口
│   ├── src/                   # 35+ 模块：clarify/outline/write/redteam/
│   │                          #   reader-gallery/style/style-pulse/style-adapter/
│   │                          #   style-eval/style-memory/library/genre/rag/
│   │                          #   fact-check/proofread/originality/transform/
│   │                          #   history/profile/citation/io/director/mcp/…
│   ├── scripts/io/            # docx/xlsx/PDF 处理（python）
│   └── test/                  # e2e 全链路（离线 mock LLM，180 项断言）
├── skills/sculptor/           # 可安装 skill（内嵌 engine 快照 + SKILL.md + hooks + references）
├── scripts/                   # 安装/引擎同步/本地 LoRA 训练
├── docs/PRODUCT.md            # 本文档

└── .github/workflows/ci.yml   # 离线 e2e + 防漂移 + 冒烟
```

## 七、安装与快速开始

```bash
# 一键安装（目录级，不影响其他项目）
curl -fsSL https://raw.githubusercontent.com/zhangyoufu-123/sculptor-agent/main/install.sh | bash
# 或
git clone https://github.com/zhangyoufu-123/sculptor-agent && cd sculptor-agent && ./install.sh

# 配置 LLM（默认 DeepSeek 端点）
export SCULPTOR_LLM_API_KEY=sk-xxx

# 在你的写作项目里直接开始（skill 内嵌完整引擎）
node .codex/skills/sculptor/scripts/sculptor.mjs init
node .codex/skills/sculptor/scripts/sculptor.mjs agent   # 导演模式，主导全程
```

常用命令速查：`clarify` 澄清 · `outline` 大纲 · `write` 写作 · `redteam` 审计 · `style --pulses` 脉搏 ·
`transform polish|expand|condense|imitate|tone:formal` 改写 · `dictate` 语音口述 · `export --docx|--pdf|--srt` 导出 ·
`fact-check` 事实核查 · `proofread` 校对 · `rag ingest` 检索回灌 · `history/rollback` 快照回滚 ·
`profile export/import` 风格档案随身 · `cite` 参考文献 · `mcp` 启动 MCP 服务器。

## 八、质量保证

- **离线全链路 e2e**：180 项断言覆盖澄清→大纲→写作→审计→群像→交付、风格、RAG、导出、快照、MCP；
- **防漂移**：CI 校验 skill 内嵌引擎与 agent 一致；
- **退让协议**：任何外部修改都不覆盖（并发守卫 + 哈希校验）；
- **离线兜底**：所有 LLM 环节在无密钥时确定性降级，几毫秒返回；
- **外部进程超时**：whisper/python 全部带超时，绝不阻塞主流程。

## 九、路线图

- **已落地（v0.8–v0.13）**：风格保真闭环、大纲评审、公文国标、读者交锋、持续微调管线、事实核查、语音口述、多格式导出、校对、联网 RAG、改写矩阵、版本快照、全局风格档案、引文管理、静默质量门。
- **可选（P2）**：流式输出、TTS 听读、PPT 联动、模板市集、多语言翻译——按真实场景按需补，不碰写作主线。
