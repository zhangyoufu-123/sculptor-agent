# 写作对话引导参考 · 优质问答记录

> 用途：为写作 Agent（Stylotrace 及同类）提供"如何引导用户说出优质回答"的参考。
> 依据：两场完整写作对话——散文《再见》（2026-08-07）、中篇小说《差生》（2026-08-07）。
> 性质：归纳原则与模式，非死记硬背的问答脚本。

## 一、优质用户回答：长什么样（核心）

优质回答不是"说得长"，而是**可写作者（writerly）的回答**——能直接变成素材、结构、隐喻或风格指令。它有六个可判定的质量维度：

| 维度 | 定义 | 实例（两场会话原话） |
| --- | --- | --- |
| 具体（concrete） | 有画面、有细节、有可引用的原话 | "那几棵银杏，一架葡萄藤""名单贴出来的那天……心里空空的" |
| 情感真相（truth） | 有悖论、矛盾、不完美 | "我可曾受过什么冷漠？我可有什么可抱怨？没有，但我在再见时却这样痛苦" |
| 独特意象（image） | 用户自发的隐喻，最强素材 | "毕业就是那个戈多""手中已经空无一物了，眼前却还有的" |
| 方向与立场（stance） | 一句话给价值取向 | "私人纪念，生活简单，要有心思放在这些琐事上""抨击社会，促进社会进步" |
| 可操作（actionable） | 具体到词/句怎么改 | "'好'改为'挺好'""毕业证的意象太直白了，更换一个" |
| 修正即需求（correction） | 否定之后给出真需求 | "不不不……这些作案背后有的只是悲凉和反抗……审判中他帮过的人、亲近的人都落井下石" |

### 回答质量分级（L0–L5）

| 级别 | 类型 | 特征 | 例子 | 价值 |
| --- | --- | --- | --- | --- |
| L0 | 空答 | "随便""你看着办" | — | 无信息，仅表示放弃 |
| L1 | 方向型 | 选一个字母或一句方向 | "b"（姿态型差生）；"私人纪念" | 锁定关键决策点 |
| L2 | 素材型 | 给具体事件、原话 | "北京中学一年年总有机会提前进高中，我都没有选上" | 变成正文细节与伏笔 |
| L3 | 结构/隐喻型 | 自发给出递进与隐喻 | "要有一种细细的递进""毕业就是那个戈多""人生就是一场空，只有在空中找到琐碎，才满了" | 重塑全篇结构 |
| L4 | 修正型 | 否定＋新需求 | "真善美不是甜蜜……是悲凉的反抗" | 纠正方向，价值最高 |
| L5 | 精准指令型 | 具体到词/句/写法 | "'好'改'挺好'；说话要有双引号；留白不能一直留，要有实有虚" | 直接可执行，进风格档案 |

**Agent 的引导目标：把用户从 L0/L1 逐步推向 L2–L5。** 一次一问的澄清期负责收集 L1–L3；用户的"不不不"与修改指令是最珍贵的 L4–L5 信号，必须接住。

## 二、Agent 怎么引导用户说出优质回答（10 条技术）

### 技术 1：降低回答成本——永远带"我的建议＋A/B/C"
- 做法：每个问题先亮我的理解/推荐，再给 2–3 个真实方向（每个都代表一个站得住的写法，不是陪跑项）。
- 例证：《差生》问"差生是哪种坏"给"实锤型／姿态型／混合型"，并说明"姿态型最锋利"的理由。
- 为什么有效：用户不必对着空白答题，点一个字母或改一句话即可推进；选项给了"可纠正的锚"，用户点头或改口都比空答准确。

### 技术 2：从用户原话里挑最亮的点追问，不跳回清单
- 做法：接住用户刚说的画面或悖论，沿它深挖一层。
- 例证：《再见》用户说"无可抱怨却痛苦"→ 下一问直接问"这份痛苦里，最扎心的是失去还是从未拥有"，把抽象情绪逼成立意选项。
- 为什么有效：用户在自己刚说出的话上补充，最省力也最真实；模板问题（"你最近有没有一件事想写下来"）被用户无视过。

### 技术 3：先亮"我的理解"，请用户点头或纠正
- 做法：把用户散落的表达拼成一句，问"对吗？"。
- 例证：《再见》把立意拼成"那些我以为空空如也的日子，原来就是我的整个初中……"，用户选了更深的 C（空与满的悖论）。
- 为什么有效：点头/纠正比让用户自己造立意容易得多，而且"纠正"往往就是 L4 级高价值回答。

### 技术 4：用"不要什么"反向引导
- 做法：用户否定建议时，不辩解、不回退，立刻追问或提炼"那你要的是什么"。
- 例证：《差生》用户连说"不不不"拒绝甜蜜真善美后，补出"悲凉和反抗"＋"落井下石"——一次否定换来全篇最核心的结构。
- 为什么有效：否定是未被满足的需求，把它翻译成"要什么"，用户会给出比第一次更精准的表达。

### 技术 5：回显整篇蓝图，让用户做全篇级校正
- 做法：核心信息齐后，把"叙述方式→三幕结构→伏笔→情感曲线→结尾"整体回显，问"对吗？"。
- 例证：《差生》蓝图确认后，用户后续的戈多隐喻、欧亨利结尾都是站在"全篇"层面给出的修正。
- 为什么有效：看整体时，用户给出的反馈天然是 L3/L5 级（结构、收束），而不是碎片。

### 技术 6：让用户看见"自己被认真记录"
- 做法：每轮附确认清单（✓/…、进度 x/9），用户原话进素材表，修改进风格档案并明示。
- 例证：两场会话用户都能看到"你刚才那句话已经记进素材/风格档案"。
- 为什么有效：用户确认自己给的东西被使用，就更愿意给细节和精准指令；"看得见"本身就是激励。

### 技术 7：给"为什么"，不只给选项
- 做法：推荐项附理由（"姿态型没有实锤，讽刺才最狠"；"陌生人最荒诞、最局外人"）。
- 例证：《差生》每轮 A/B/C 都带一句推荐理由，用户多次直接采纳。
- 为什么有效：用户能基于理由修改方向，而不是盲选；理由也帮用户形成自己的判断语言。

### 技术 8：控制问题粒度——小问题与大问题交替
- 做法：选型类小问题（死者是谁、体量多大）与立意/结尾类大问题交替，避免连续疲劳。
- 例证：两场会话都是"素材细节 → 立意 → 结尾姿态 → 风格底稿"的节奏，用户全程高投入。
- 为什么有效：连续大问题会累，连续小问题会碎；交替让用户既有掌控感又有思考空间。

### 技术 9：把用户的修改变成"风格教学"，强化指令习惯
- 做法：每次定点修改后明示"已吸收进风格档案，以后按这个来"。
- 例证：《差生》"心不在焉的冷漠对话"进 styleDirections 后，后面所有对话自动遵守；《再见》"暖意反噬成刺痛"同理。
- 为什么有效：用户学会"给一句精准指令＝永久改变文风"，会持续给 L5 级指令。

### 技术 10：展示回报——让用户看到优质回答换来的结果
- 做法：把读者群像里被素材打动的话转达给用户。
- 例证："一个被全世界叫差生的孩子，被陌生人叫同学，他居然没有纠正"——用户最珍惜的细节被读者接住。
- 为什么有效：用户看到"给得具体＝写得更好"，形成正向循环，主动往 L2–L5 走。

## 三、两场会话速览

| 项目 | 散文《再见》 | 中篇小说《差生》 |
| --- | --- | --- |
| 用户开局 | 只给题目：散文，题目《再见》 | 给详细 brief：局外人式第一人称＋固定终场台词 |
| 澄清轮次 | 约 8 轮（一次一问） | 约 7 轮（一次一问） |
| 关键素材 | 银杏/葡萄藤、无友无恋、等待戈多、空与满 | 姿态型差生、意外卷入、陌生人死者、落井下石 |
| 用户改动 | 6 次定点修改 | 10 条改进建议（对话、引号、口语、独白、欧亨利结尾） |
| 质检闭环 | 红队＋校对＋读者群像＋导出，每轮重跑 | 同左，共跑 6 轮读者群像 |
| 最终交付 | 散文 + 对话整理 | 中篇 + 参赛稿 + 对话整理 |

## 四、用户画像（两场会话共有的稳定偏好）

1. 作品有明确价值立场：抨击社会、促进进步；讽刺要犀利，但藏在白描里。
2. 拒绝"模板感"与"甜蜜感"：真善美是"悲凉的反抗"，不是温馨桥段。
3. 要求克制但有实有虚：可留白，但哲学与情感在关键处必须完整说出。
4. 对"AI 味"敏感：修辞堆砌、"他说/我说"标签化、"好"这类书面应答都会被点出。
5. 重视细节与伏笔：首尾呼应、环境收束、欧亨利式反转——"细节即伏笔，结尾回收"。
6. 信号明确："可以/挺好"＝推进；"不不不"＝方向错了，要从否定里提炼真需求。

## 五、引导原则（13 条，归纳）

1. 一次一问，永远带"我的建议＋A/B/C"（单问句硬规则）。
2. 从用户原话生长，接住有画面感的表达。
3. 确认清单可见化，核心维度未确认不进大纲。
4. 核心信息齐后，回显整篇蓝图请用户确认。
5. 作者拍板的点给选项，用户给定的台词/结局一字保留。
6. 每句话都是素材，每次修改都是风格信号。
7. "可以/挺好"是推进信号，不是敷衍。
8. 每轮修改都走"局部重写 → 红队 → 读者群像 → 重导出"闭环。
9. 读者群像批评分三类：共识直接改、争议交用户拍板、噪音忽略并说明理由。
10. 风格执行要"克制又到位"：留白与完整独白并重。
11. 口语化是第一人称真实感的命门（引号、挺好、裸对话＋注意力漂移）。
12. 反转必须"意外却合理"，靠伏笔回收，不靠巧合。
13. 交付透明＋主动文件化（字数/质检/争议/文件清单＋"用户建议时间线"）。

## 六、问答模式拆解（类型 → 引导策略）

| 用户输入类型 | 引导策略 |
| --- | --- |
| 只给题目/文体 | 先问体量与读者/场合（影响全局的一个），再挖素材 |
| 给详细 brief | 拆成确认清单，只问剩余空白（事件细节、人物动机、反转落点） |
| 给抽象方向（"要细细的递进"） | 给具体化建议＋选项，让抽象落地 |
| 拒绝第一个建议（"不不不"） | 从"不要什么"提炼真需求，不回退到模板 |
| 给固定台词/结局 | 一字保留，视为最高优先级素材 |
| 说"可以/挺好" | 推进信号，直接下一步 |
| 说"你决定" | 才可替用户决定；连续两次才放弃可选维度 |
| 给出修改指令 | 立即执行＋吸收进风格档案＋重跑红队/群像/导出 |
| 要对话记录 | 结构化归档，重点标出"用户建议时间线" |

## 七、易踩的坑（复盘反面清单）

1. 模板化提问 → 用户觉得没被理解；改用用户原话重组问题。
2. 把"真善美"写成温馨桥段 → 用户要的是悲凉与反抗，不是甜。
3. 对话标签堆砌（他说/我说）→ AI 味；用裸对话＋动作＋注意力漂移。
4. 一味留白或一味说破 → 都要"有实有虚"。
5. 欧亨利结尾生造巧合 → 必须回收已有伏笔。
6. 红队软指标（句首去重、TTR）在第一人称长文不达标 → 说明文体特征，不硬凑。
7. 读者质疑立场（"给犯罪找借口"）→ 是用户立场与作品锋芒，如实说明并交用户拍板，不擅自稀释。

## 八、给 Agent 的操作速查

- 澄清期：一次一问＋建议＋A/B/C；清单可见；素材原话入档；核心未齐不动笔；**目标是把用户推向 L2–L5**。
- 大纲期：蓝图回显确认；每章挂功能＋字数；用户确认才写。
- 写作期：按风格档案执行（口语、引号、克制与独白并重）；逐章核字数。
- 修改期：定点改＋吸收＋红队＋群像＋重导出；把 L4/L5 指令明示进档案。
- 交付期：字数/质检/争议/文件透明；主动给"建议时间线"记录。
