# Stylotrace 产品定位:主体用户 · 使用场景 · 对应能力

> 目的:明确"为谁做、解决什么、靠什么赢",让宣传与产品优化都对准真实需求。
> 版本:随 v0.1.8 更新。

## 一、主体用户(按优先级)

| 优先级 | 人群 | 画像 | 为什么是主体 |
|---|---|---|---|
| **P0** | **用 Agent 的技术 + 内容创作者** | 程序员、独立开发者、创业者——已经在用 DSH / Codex / Claude Code | ① 写作是高频刚需(报告/README/博客/文档);② 痛点最痛("我做出了东西,但不想写");③ 已在生态里,零获客成本 |
| **P1** | **职场文字工作者** | 汇报、邮件、方案、文案的写作者 | 场景高频、明确;核心诉求"像我的风格"+"学领导/同事的风格" |
| **P2** | **文学写作爱好者** | 写散文/小说、想学名家笔法的人 | 低频但高情感价值,传播力强("学鲁迅/史铁生写一段") |

## 二、核心使用场景(痛点 → 能力映射)

| 场景 | 用户原话 | 痛点 | 对应能力 |
|---|---|---|---|
| 项目 → 报告 | "帮我把这个项目写成产品介绍" | 做出了东西,不会写 | `synthesize`(项目自动提炼,零逐项交代) |
| 去 AI 味 | "这文章一眼 AI,帮我改得像人" | 生成内容套话/排比/平整 | `humanize` + `humanizationScore` + `polish` |
| 学某人风格 | "学我同事的周报语气" / "学鲁迅写一段" | 想借用他人文风 | 风格学习 + **内置名家预设**(鲁迅/老舍/朱自清/徐志摩/郁达夫/史铁生) |
| 越写越像自己 | "以后都按我的风格写" | 每次都要重新描述自己 | 四层风格向量 + 外层调制器(几十次修改即稳定) |
| 定点改一句 | "这句太文艺,收一点" | 只想改一处,不想整篇动 | `point_edit` + Web 选中「✨ 改进」 |
| 写完不放心 | "帮我看看有没有硬伤" | 缺客观质量把关 | `redteam` + `fact_check` + `audience` + `polish` |

## 三、产品优化方向(按此落地)

1. **开箱即用(0 门槛)** —— 零依赖、自动发现凭据、内置名家预设,装完 30 秒出效果;
2. **每个场景一句话入口** —— 用户说一句话,Agent 自主走完(自由式导演,少硬编码);
3. **少 token 读风格** —— 风格注入轻量化(Top-6 高置信维度 + 锚点原句,节省 59%);
4. **与生态共生** —— 只写自己的工作区、生态位外让位、可被任何 Agent 作为写作子 Agent 调用。

## 四、差异化一句话(传播用)

> **DSH 生态第一个"会学你、也会学名家"的写作 Agent**:
> 从项目里替你成文,从修改里学你文风,从名家笔墨里借笔法——AI 替你写,但像你(或像你指定的任何人)写的。
