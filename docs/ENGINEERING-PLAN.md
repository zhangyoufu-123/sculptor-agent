# SCULPTOR Agent 工程计划（v1.6 → 行业顶级）

> 目标：把"改迹调制（revision-trace modulation）"这条创新主线，从"可解释、可学习的
> 候选级原型"推到"行业顶级的小样本风格注入"，并保证真实可用。
> 本文同时是工程计划与论文素材记录（过程性思考见第 6 节，持续追加）。

## 0. 现状基线（诚实评估）

核心已落地（v0.68）：

- 12 维外层调制器 `modulator.js`：偏好对 pairwise hinge + L2 + SGD/momentum，z-score 归一化，
  数据签名缓存，增量在线更新，贡献分解 + 人话理由（`contributionBreakdown` / `humanRationale`）。
- 候选对比解码 `token-decode.js`：每节并行生成 n 候选 → 12 维评分选优 → 返回 breakdown。
- 个人模型 `personal-model.js`：字符 4-gram + 回退 + 加一平滑，`personalLogProb` 平均每字对数概率。

与"行业顶级"的明确差距（按严重度排序）：

1. 个人模型太弱：字符 4-gram + 加一平滑，只能抓表面字符分布，抓不住语义/结构/功能词风格。
   这是"预测作者怎么写"这一论文主张最薄弱的落点。
2. 特征多为手写启发式：`defect`/`surface`/`discourse`/`posture` 等是词表命中 + 句长统计，
   不是学习到的表征；学习只学 12 个标量权重，本质是"线性重排候选"，不是真正的风格迁移。
3. 无逐 token 控制：候选级 n 默认只有 2；V2 logprobs 实测只返回 `reasoning_content`（思考链）
   不返回 `content`（成品），V3 本地 logits 未做。
4. 小样本冷启动失效：`decodeN` 在个人语料 <200 字符时返回 1，直接关闭对比解码——
   与"小样本风格注入"的定位自相矛盾。
5. 评测证据弱：学习曲线用 30 条合成编辑对；作者识别 81.7% 低于 TF-IDF 基线 82.2%；
   无第三方盲评、无显著性、无消融。
6. embedding 第 9 维通常未配置（静默降级到中性 0.5），语义风格信号缺失。

## 1. "行业顶级"的可测量目标

| 指标 | 现状 | 目标 | 验收方式 |
| --- | --- | --- | --- |
| 作者识别 | 81.7%（< TF-IDF 82.2%） | ≥ 85% 且显著高于基线 | 真实多作者语料 + 交叉验证 + 置换检验 p<0.05 |
| 续写选择 | 72.2%（随机 50%） | ≥ 80% | 盲评 + 二项检验 |
| 小样本生效 | 需 200 字符才启用对比 | 1–5 条编辑即可产生可测增益 | 冷启动单测 + 小 n 学习曲线 |
| 风格距离 | 0.96（ChatGPT 1.24） | 维持/拉大 | style-vectors.py |
| 消融 | 无 | 学习权重 > 默认权重 > 逐维关闭 | 逐维消融实验 |

## 2. 创新点深化路线（核心）

主线不变：编辑即标注。深化方向是把"编辑"用得比现在深得多，并补齐"风格是分层的"这一盲区。

### 2.0 风格是分层的（新增核心原则）

风格不是单一向量，而是四个层级的联合：

- 文档级（整篇构成 + 起承转合）：段落/章节数量与分布、开篇—承接—转折—收束的弧线。
- 话语级（论证/叙事结构）：修辞 moves、论证链、伏笔—回收节奏。
- 句子级（句法/节奏）：句长波动、标点节奏、句首模式。
- 词级（用词习惯）：功能词、意象、口语/书面、个人回避词。

现状：12 维调制器只覆盖句子级和词级，文档级和话语级是盲区，这是本次深化要补的最大一块。

### 2.1 从"编辑→权重"升级为"编辑→变换模型"（最关键的深化）

现状：编辑对只被压缩成 12 个标量权重（线性重排候选）。
深化：把每个（原文→改后）当作一条局部风格变换，学习"作者会怎么改"，并把变换
应用到 LLM 候选上，而不只是给候选打分。具体分两步：

- A. 编辑变换分类器（零依赖）：从 edits.jsonl 归纳出可解释的变换类型
  （抽象→具体、AI 腔→克制、长句→短句、连接词→句号断裂、书面→口语等），
  训练一个轻量判别器，能判断"候选文本最可能被作者做哪种改"。
- B. 变换应用层：写作时对每个候选先跑判别器，再按作者高频变换做一次"拟改"
  （可解释、可追溯），让调制从"选优"变成"选优 + 拟改"。

意义：这直接呼应论文的"改迹"（revision-trace）字面含义，把创新从"评分函数"抬到
"可学习的编辑策略"，且仍保持零依赖、可解释。

### 2.2 个人模型升级：char n-gram → 分层作者语言模型

- 在 char 4-gram 之上叠加：词/子词 n-gram + 功能词分布 + 标点节奏 + 句首模式（仍零依赖）。
- 编辑对按"original 作负例、changed 作正例"显式进入语料，强化差异信号（当前只用 changed）。
- 维护"作者风格词表"（高频实词/虚词/意象），作为可解释的 p_personal 组件，也让"为什么像你"能被讲清。

### 2.3 特征从"手写"升级为"手写 + 统计 + 语义"三层

- 保留 12 维可解释框架，但每维底层升级：`defect` 从静态词表 → 结合"作者亲手删掉的词"频率；
  `surface`/`discourse` 加入与作者语料的相对统计（而非绝对规则）。
- embedding 第 9 维：提供本地零依赖降级（字符 TF-IDF 余弦代理），不再静默缺失。

### 2.4 小样本冷启动（必修，当前是硬伤）

- `decodeN` 阈值从 200 字符降到"≥1 条编辑对即启用对比解码"。
- 单段短样本也能提取最小指纹（句长均值/方差、标点密度、意象命中）。

### 2.5 评测体系升级（行业顶级证据）

- 真实多作者语料（脱敏）+ 强基线（TF-IDF、char TF-IDF、无调制基线）。
- 交叉验证 + 置换检验 + 逐维消融 + 学习权重 vs 默认权重对照。
- 盲评落地：`sculptor experiment blind-stats` 已有，补齐一键收集 + 报告。

### 2.6 文档级风格：起承转合 + 整篇构成（新增，补齐多层盲区）

- 起承转合弧线特征：对候选文本做"开篇/承接/转折/收束"四段识别（转折词、收束标记、段落位置、
  情感极性的弧线走向），与作者典型弧线比对（对应 Reagan et al. 2016 的六种情感弧线）。
- 整篇构成特征：段落数、段落长度分布、章节节奏、开合方式，作为文档级维进入评分。
- 话语级特征：论证链完整性、伏笔—回收节奏（复用现有 `outline.js`/`reader-gallery.js` 的结构信号）。

### 2.7 外围算法集群（无 LoRA 的推理期控制，替代微调）

不做 LoRA，改用一簇推理期算法共同影响大模型判断，按 DExperts/对比解码范式组织：

- 对比解码（DExperts 式）：`personal`（expert）vs `avoidance`（anti-expert）做解码期对比，
  惩罚"反专家也高概率"的候选——把现有"打分"升级为"对比影响"。
- 候选重排 + 拟改：现有 12 维评分 + 2.1 的编辑变换模型。
- 前缀/提示引导（PREADD 式）：用作者风格画像做前缀注入，影响生成方向。

对应文献：DExperts（Liu 2021）、Contrastive Decoding（Li 2022）、StyleVector（Liu 2025）、
Activation Addition（Turner 2023）。

## 4. 分阶段计划（带验收）

### Phase A — V1.6「小样本 + 强基线」（先证明"少样本也能学"）

- 2.4 小样本冷启动；2.5 强基线 + 置换检验 + 消融框架。
- 个人模型加"编辑对负例"（低成本、立即增强）。
- 验收：1–5 条编辑的学习曲线可测出增益；作者识别跑通强基线 + 置换检验，明确差距数字。

### Phase B — V1.7「编辑变换模型 + 特征升级」

- 2.1 编辑变换判别器 + 拟改层（核心创新深化）；2.3 特征底层升级；2.2 词级个人模型。
- 验收：消融显示"变换应用层"带来额外增益；作者识别接近/超过 TF-IDF 基线。

### Phase C — V1.8「V2/V3 探测 + 盲评 + 论文硬指标」

- B6 V2 logprobs 再探测（换非推理模型变体试 `logprobs.content`）；本地 logits 可行性评估。
- D1 盲评收集（10–20 人）+ 精确二项 + 效应量；论文 7 节局限按实测更新。
- 验收：盲评"更像作者"显著高于随机；论文硬指标闭环。

> Web 改造与论文/PPT 在 agent 达到 Phase A 验收后另行启动（遵循"先 agent 完美"的顺序）。

## 5. 复用的关键约束（勿违背）

1. 零依赖、skill 内嵌、可解释可追溯（不引入重 ML 运行时）。
2. 软性加权，作者保留否决权，无拒绝式硬约束。
3. 数据纯净性：知识库/检索内容不进风格语料。
4. 改 agent/src 后必须同步 `skills/sculptor/scripts/engine/`。
