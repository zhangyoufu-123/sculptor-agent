# 作者识别实验（初版，v0.54）

> 方法：6 类真实文本样本 → 滑窗切块（80 字/步 40）→ 60/40 随机划分 × 12 轮 → 最近质心分类。
> 基线：字符二元组 TF-IDF + 余弦。本系统：L1 字符二元组 + 8 维可解释风格特征（z 归一化）。
> 拟合纪律：TF-IDF 的 IDF 与 z 归一化参数只在训练集上估计，避免特征泄漏。

| 特征路线 | 平均准确率 | 测试块数 |
| --- | --- | --- |
| 基线（TF-IDF 二元组 + 余弦） | 82.2% | 180 |
| 本系统·8 维风格特征 | 32.2% | 180 |
| 本系统·L1 二元组 + 8 维融合 | 81.7% | 180 |

## 诚实解读（评审重点）

1. **8 维聚合特征单独判别力弱（32.2%）**：证明"几个统计指标"不足以支撑作者识别；
   判别力主要来自 L1 字符二元组（词汇层信号），这与"作者高频用字签名"的定位一致；
2. **基线 82.2% 高于纯 8 维**：我们如实承认，当前签名在判别任务上**没有显著超越**
   简单 TF-IDF 基线——这恰说明"签名（profile）≠ 模型（model）"；
3. 融合路线（L1+8 维）介于两者之间，说明 8 维特征提供的是互补但次要的信号；
4. 正式结论依赖更大的多作者 × 多篇跨文体语料 + 同题材混淆集 + 显著性检验。

## 诚实局限（必须阅读）

1. 每作者仅 1 篇样本，切块来自同一文档——主题与文体信号与作者信号混杂，准确率会被高估；
2. 本实验是"判别力初证 + 方法演示"，不能作为"超越简单基线"的最终证据；
3. 正式实验需 5-10 位作者 × 多篇跨文体文档 + 同题材混淆集 + 与 TF-IDF 基线的显著性检验；
4. 更根本的"作者模型"检验是**预测实验**：给定前文预测作者下一步选词/句子重心，
   命中率显著高于基线才算学到"模式"（列入未来工作）。

复现：`python3 scripts/author-id.py`（确定性种子，无随机漂移）
