# 作者识别 v2（真实 JS 签名 + 置换检验）

> 语料：9 类单篇文本 → 滑窗切块（80/40）→ 60/40 × 12 轮 → 最近质心/最大似然分类。
> 基线：字符二元组 TF-IDF + 余弦。本系统：个人 n-gram 似然 + 12 维特征的文本子集。
> 诚实边界：同文切块高估准确率；本报告不用于"宣称超基线"，仅定位差距与显著性。

| 路线 | 准确率 | vs TF-IDF 差值 | 置换 p |
| --- | --- | --- | --- |
| TF-IDF 基线 | 90.3% | — | — |
| 个人 n-gram（似然） | 46.3% | -44.0% | 0 |
| 文本特征（5 维，最近质心） | 34.3% | -56.0% | 0 |
| 融合（n-gram + 特征） | 46.3% | -44.0% | 0 |

置换检验（融合 vs 基线）：不一致样本 97，p=0（显著）

结论：以当前单篇合成语料，真实 JS 签名的判别力尚未显著超越 TF-IDF；这是 v1.6 要攻克的硬指标。
