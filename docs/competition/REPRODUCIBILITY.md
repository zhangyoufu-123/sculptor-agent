### 2. 调制器逐维消融（5.7，图 9）

复现：`node scripts/experiments/modulator-ablation.mjs` -> `MODULATOR-ABLATION.md`

| 变体 | 留出排序正确率 |
| --- | --- |
| 学习权重 | 100.0% |
| 默认权重（无学习） | 100.0% |
| 关闭 personal | 90.0% |
| 关闭其余 12 维（逐一） | 100.0% |

正文结论：排序正确率在两类权重下均饱和到 100%（编辑对差异过大，正确率无法区分二者）；personal 是唯一有边际贡献的特征（关闭掉到 90%）。学习有增益的可靠证据来自学习曲线留出边距，而非消融正确率。

旧版正文曾写"学习权重 90% 高于默认权重 70%"，与实测不符，已删除。

## 四、复核建议

- 零 LLM 实验可在任何装有 Node 18+ 与 Python 3.9+ 的环境离线重跑，结果应逐位一致。
- LLM 依赖实验建议以 `STYLOTRACE_MOCK_LLM=1` 先验证脚本可运行，再以真实 DeepSeek key 重跑；分数会因模型与随机性小幅波动，结论（风格可辨、朴素模仿不足）不变。
- 论文正文数字以本表为准；图由 `gen-paper-charts.py` / `gen-flow-diagrams.py` 从同一数据源生成。
