# Sculptor —— 会读你、懂你、替你写好的深度协作写作 Agent

> **一句话**：Sculptor 不是"AI 帮你写文章"，而是**一个读得懂你的写作合伙人**——它先弄清你想说什么、怎么想、像谁写，再动笔；写完之后，它会像最挑剔的编辑和第一读者那样审自己。

## 为什么需要它

通用 AI 写作的痛点是"一眼假"：结构工整、辞藻平滑、却没有人味。根因不是模型不够聪明，而是**它不认识你**——不知道你读过什么、在意什么、怎么写才像你自己。

Sculptor 用一套完整的人机协作协议解决这件事：**风格不是模仿，是提取**；**素材不是凭空生成，是从你的知识库里生长**；**流程不是生成一次完事，是澄清→大纲→写作→复阅→审计→读者群像的完整闭环**。

## 它是什么

一个可装入 **Codex / Claude Code / OpenCode / Cursor** 的深度写作 Agent（Skill 包 + 完整引擎 + MCP 服务），能主导从"一个念头"到"一篇可以交付的文章"的全过程：

- **澄清**：一次一问，从你的原话里生长问题，不套模板、不死板追问；你心里有个模糊想法，它帮你把它说清楚。
- **风格**：从你读过的书、写过的文、反复改过的地方里，提取出**你的**风格向量与"人物风格肖像"，而不是模仿某个名人。
- **知识**：你读过的书、去过的地方、自己的理论，会被归纳成可查询、可迁移的个人知识库；你没想到的相关书籍，它会主动推荐并说清"为什么适合你"。
- **写作**：论文有论证链、小说有角色预演、公文有范式、长文有文章圣经——按文体走对的路径。
- **质量**：反 AI 痕迹审计、事实核查、读者群像反馈、情绪曲线检查，全部真实触发。

## 三大护城河

### 1. 风格：从不规范表达与完美表达的差异里提取

我们把"风格"定义为**人天然的不规范表达与完美表达的差异弥补**——不可预测、有困惑性、来自注意力残差和个人有限知识库中的无限联想。Sculptor 用四层复合风格向量（连续向量 EMA + 动态素材/意象维度 + 困惑度签名 + 偏好对）持续追踪，并叠加"人物风格肖像"侧写，让 AI 越写越像**你**，而不是像"AI 眼中的你"。

### 2. 知识：读过的书是写作的土壤

个人知识库（PKB）不是文件堆：它归纳式采集你读过的《书名》、去过的地方、自己的构想；写作时按主题检索、轮换注入、绝不反复引用同一本；可以随人迁移（export/import）。内置思想库与联网检索（RAG）打通，荐书联想会主动递上与你想法相近的经典，并解释"这个理论是什么、为什么可以用"。

### 3. 协作：写作生态位内主导，生态位外让位

在 Codex 等 Agent 环境里，Sculptor 占据"写作"这一生态位：需要数据时自动排队检索（澄清/大纲/写作三处实时取数），宿主或学术/数据分析 Agent 检索回灌后，它会自动用新数据重写缺口节；在编程、答疑、翻译等领域则完全让位，绝不与其他 Agent 打架。

## 一段完整工作流

```
你说一个念头
  ↓  澄清（一次一问，风格/知识/数据同步采集）
  ↓  大纲（论证链或故事骨架，你确认后才写）
  ↓  逐节写作（注入你的风格肖像 + 知识库 + 角色预演）
  ↓  复阅-修订（初稿自查：偏题/衔接/素材用足）
  ↓  反 AI 审计（黑名单/重复比喻/句式，自动修订）
  ↓  读者群像（8 个"第一读者"的感性反馈 + 交锋收敛）
  ↓  交付（归档个人写作库 + 沉淀文章圣经 + 导出 docx）
```

全程你只回答"该你决定"的问题，其余由 Sculptor 自主推进。

## 质量与可信

- **337 项自动化断言**覆盖澄清→大纲→写作→审计→群像→交付全链路、风格向量、知识库、实时取数、MCP、安全。
- **反 AI 审计**：禁用套话黑名单、重复比喻检测、句式查重；红队+自动修订最多 3 轮。
- **确定性兜底**：任何 LLM/网络不可用时，流程降级不崩溃。
- **安全**：密钥自动发现但绝不打印；提交前密钥扫描；个人数据 0600 权限、工作区隔离。

## 上手

```bash
curl -fsSL https://raw.githubusercontent.com/zhangyoufu-123/sculptor-agent/main/install.sh | bash -s -- --all
```

然后在任何写作项目里说："写一篇关于××的散文，要有我的风格"——Sculptor 会接管。
