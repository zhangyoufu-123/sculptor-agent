# 真实用户走查清单（v1.0 商业化验证）

> 用途：用真实用户在 Web 上从"装到写"完整走一遍，逐项打勾，定位"真实可用"的最后一公里。
> 运行：`cd web && npm start`，浏览器开 `http://localhost:5177`。

## A. 安装与启动（3 项）

- [ ] 一条命令启动成功，终端打印 `Stylotrace Studio → http://localhost:5177`，且显示 `密钥: 已配置`
- [ ] 打开首页无白屏、无 500，标题、侧栏、输入框正常渲染
- [ ] `/health` 返回 `{ok:true, model:..., key:configured}`

## B. 澄清式写作（6 项）

- [ ] 输入一个写作念头，agent 先提问、一次只问一个，而不是直接甩稿
- [ ] 连续回答 4–6 轮，问题逐步收窄（主题→立意→素材→读者），不跑题、不重复
- [ ] 右侧"上下文"面板随对话实时更新（大纲/进度/素材/风格脉搏）
- [ ] 出现大纲并确认后，进入逐节写作，不卡死、不死循环
- [ ] 每次回答后页面不闪退，刷新后能回到原会话继续
- [ ] 写作期间右上角"改迹"标签能显示十三维贡献分解

## C. 风格学习（4 项）

- [ ] 导入一篇自己的旧稿（作品库/上传 md），agent 后续写作明显更像本人
- [ ] 对成稿做一次批注/选段改写后，"改迹"面板出现"改前 vs 改后"对比
- [ ] "风格肖像"页能看到雷达图与人物侧写
- [ ] 新建第二个会话，第一个会话学到的东西不串味（按机器隔离）

## D. 导出与交付（4 项）

- [ ] 导出 md / docx 成功，docx 打开格式正常（标题/加粗/表格保留）
- [ ] 导出审计报告，能看到人类化指标（句长/段落/句首/TTR）
- [ ] 学术/公文文体的学术规范审计、文档翻译、风格重写工具可用
- [ ] 全程无一次 `500 / 空白 / 控制台报错`

## E. 安全（2 项）

- [ ] 设置 `SCULPTOR_WEB_PASSWORD` 后，未登录访问 API 返回 401，登录后正常
- [ ] 未设密码时，明确知道这是"开放实例"，不对外公开

## 结论

19 项全部打勾 = 可交付商业用户；任何一项失败 = 记录现象（截图 + 终端输出）回来定位。
